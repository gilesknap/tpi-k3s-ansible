# Tutorials

Two walks through the cluster, start to finish. The tour looks round the
running cluster without changing anything; the build tutorial is the one
end-to-end path from powered-off hardware to that running state. Both are
written for gkcluster.org as it is: the owner follows them as they stand, and
a visitor reads them to see what such a cluster involves.
